## 1. プロジェクト概要

### 1.1 目的
テキスト（ストーリーや概要）を入力すると、AIが自動的に漫画のコマ割り・セリフ配置・画像生成を行い、漫画作品として出力するWebアプリケーションを提供する。

### 1.2 背景
- 漫画制作は高度なスキルと多大な時間を要する
- LLM（大規模言語モデル）と画像生成AIの進化により、テキストからのビジュアルコンテンツ生成が実用段階に到達
- クリエイターの制作ワークフローを加速し、非クリエイターにも漫画表現を開放する

### 1.3 対象ユーザー
| ユーザー種別 | 説明 |
|------------|------|
| クリエイター | プロ・アマ問わず漫画制作を効率化したい人 |
| ビジネスユーザー | プレゼン・資料にグラレコ風の漫画を活用したい人 |
| 一般ユーザー | 物語を漫画で表現したい人、SNS投稿用の漫画を作りたい人 |

### 2.5 漫画生成

| ID | 機能 | 説明 | 優先度 |
|----|------|------|--------|
| F-GEN-01 | ストーリー解析 | テキストをClaude APIで解析し、パネル分解JSON（シーン説明・カメラアングル・セリフ・効果音・ムード・登場キャラ）を生成 | 必須 |
| F-GEN-02 | 画像プロンプト構築 | シーン説明 ＋ キャラクター外見 ＋ トンマナ修飾子を合成して画像生成プロンプトを構築 | 必須 |
| F-GEN-03 | 画像生成 | 選択プロバイダー（OpenAI / Stability AI / Gemini）で並列に画像を生成 | 必須 |
| F-GEN-04 | 画像保存 | 生成画像をSupabase Storageにアップロードし、パネルレコードに紐付け | 必須 |
| F-GEN-05 | 生成進捗表示 | ストーリー解析→パネル分割→画像生成→保存の4ステップを表示 | 必須 |
| F-GEN-06 | 生成履歴 | 入力テキスト、パネル分解結果、ステータス、エラーメッセージを記録 | 必須 |
| F-GEN-07 | パネル再生成 | エディタ上で個別パネルの画像を再生成 | 必須 |

## 3. 非機能要件

### 3.1 セキュリティ

| ID | 要件 | 説明 |
|----|------|------|
| NF-SEC-01 | 認証 | Supabase Authによるセッション管理 |
| NF-SEC-02 | 認可（RLS） | 全テーブルにRow Level Securityを適用。ユーザーは自分のデータのみアクセス可能 |
| NF-SEC-03 | ルート保護 | middlewareにより保護対象パスへの未認証アクセスをリダイレクト |
| NF-SEC-04 | APIキー保護 | ユーザーのAPIキーはサーバーサイドでのみ使用 |

### 3.2 パフォーマンス

| ID | 要件 | 説明 |
|----|------|------|
| NF-PER-01 | 並列画像生成 | 複数パネルの画像生成を `Promise.all` で並列実行 |
| NF-PER-02 | インデックス | 外部キーカラムにデータベースインデックスを付与 |

### 3.3 ユーザビリティ

| ID | 要件 | 説明 |
|----|------|------|
| NF-UX-01 | 日本語UI | 全UIを日本語で提供 |
| NF-UX-02 | レスポンシブ | グリッドレイアウトにより画面サイズに適応 |
| NF-UX-03 | 進捗表示 | 生成処理のステップ進捗をリアルタイム表示 |

### 3.4 技術制約

| ID | 要件 | 説明 |
|----|------|------|
| NF-TEC-01 | フレームワーク | Next.js 16 (App Router), React 19, TypeScript |
| NF-TEC-02 | スタイリング | Tailwind CSS 4 |
| NF-TEC-03 | DB/Auth/Storage | Supabase (PostgreSQL + Auth + Storage) |
| NF-TEC-04 | LLM | Claude API (Anthropic SDK) |
| NF-TEC-05 | 画像生成 | OpenAI / Stability AI / Google Gemini（切替可能） |
| NF-TEC-06 | D&D | @dnd-kit |
| NF-TEC-07 | エクスポート | html-to-image + jsPDF |
