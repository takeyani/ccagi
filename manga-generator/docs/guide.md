## はじめに

漫画ジェネレーターは、テキストを入力するだけでAIが自動的に漫画を生成するツールです。ストーリーの分解、コマ割り、セリフ配置、画像生成までをワンストップで行えます。

このガイドでは、アカウント作成から漫画の完成・出力までの全手順を解説します。

## 1. アカウント作成・ログイン

### 新規登録

1. トップページの「新規登録」ボタンをクリック
2. 以下を入力して「新規登録」をクリック
   - **表示名**: ダッシュボードに表示される名前
   - **メールアドレス**: ログインに使用
   - **パスワード**: 6文字以上

### ログイン

1. 「ログイン」ボタンをクリック
2. 登録済みのメールアドレスとパスワードを入力

ログイン後、ダッシュボードが表示されます。

## 2. キャラクターを作る

漫画に登場させるキャラクターを事前に登録しておくと、生成時にキャラクターの外見が一貫します。

### 手順

1. サイドバーの「キャラクター」をクリック
2. 「新規作成」ボタンをクリック
3. 以下を入力

| 項目 | 説明 | 入力例 |
|------|------|--------|
| **名前** | キャラクターの呼び名。ストーリー内でこの名前を使うとAIが認識します | タロウ |
| **外見の説明** | 日本語で外見を記述。自分用のメモとしても使えます | 黒髪短髪の高校生男子。制服姿。身長175cm。明るい性格 |
| **画像生成用プロンプト** | 英語で画像AIに渡す外見指示。具体的に書くほど一貫性が高まります | Japanese high school boy, short black hair, school uniform, bright smile, 175cm tall |
| **参考画像** | イメージに近い画像をアップロード（任意） | — |

4. 「作成」をクリック

### コツ

- **画像生成用プロンプト**は英語で書くと精度が上がります
- 髪型・髪色・服装・体型・年齢・特徴的なアクセサリーを含めると一貫性が向上します
- 同じ作品に登場させるキャラクターは、見分けがつく外見にしましょう

### 例：キャラクター設定

**ヒロイン「ハナコ」の場合:**

```
名前: ハナコ
外見の説明: 茶髪ロングヘアの高校生女子。赤いリボンのヘアバンド。制服にカーディガン。
画像生成用プロンプト: Japanese high school girl, long brown hair, red ribbon headband,
  school uniform with cardigan, gentle expression, brown eyes
```

## 3. プロジェクトを作る

プロジェクトは1つの漫画作品に対応します。

### 手順

1. サイドバーの「プロジェクト」→「新規作成」をクリック
2. 以下を設定

| 項目 | 説明 |
|------|------|
| **タイトル** | 作品名（後から変更可能） |
| **画像生成プロバイダー** | 使用する画像生成AI（後述） |
| **キャラクター** | 登録済みキャラクターから選択（複数可） |
| **トンマナ設定** | アートスタイル・ジャンルなど（次章で詳説） |

3. 「プロジェクトを作成」をクリック

### 画像生成プロバイダーの選び方

| プロバイダー | 特徴 | 向いている用途 |
|------------|------|--------------|
| **OpenAI (gpt-image-1)** | 高品質・指示追従性が高い・日本語理解◎ | 万能。迷ったらこれ |
| **Stability AI (SDXL)** | スタイル表現が豊富・アニメ調が得意 | アニメ・イラスト系の作品 |
| **Google Gemini (Imagen)** | 写実表現に強い | リアル系・写真的な作品 |

## 4. トンマナ（テイスト）を設定する

「トンマナ」は漫画全体の見た目を決める最も重要な設定です。プロジェクト作成時に設定します。

### 4.1 アートスタイル

漫画の画風を選びます。14種類から選択できます。

| スタイル | 特徴 | おすすめ用途 |
|---------|------|------------|
| **少年漫画** | ダイナミックな構図、スピード線 | バトル・冒険もの |
| **少女漫画** | 華やかな背景、大きな瞳、繊細な線 | 恋愛・ドラマ |
| **4コマ** | シンプルな線、コミカルな表情 | ギャグ・日常 |
| **リアル** | 写実的、細密な陰影 | シリアス・ドキュメンタリー |
| **デフォルメ** | 誇張された表現、丸みのある造形 | コメディ・子供向け |
| **青年漫画** | 緻密な描写、重厚な雰囲気 | サスペンス・社会派 |
| **グラレコ風** | 手描きアイコン・テキスト混在、ホワイトボード的 | ビジネス資料・プレゼン・議事録 |
| **水彩風** | にじみ・ぼかし、柔らかいタッチ | 絵本的な作品・癒し系 |
| **ピクセルアート** | ドット絵、レトロゲーム的 | ゲーム系・ノスタルジー |
| **浮世絵風** | 平面的構図、太い輪郭線、日本画的色彩 | 和風・時代劇 |
| **アメコミ風** | ハッチング、強いコントラスト | ヒーロー・アクション（洋風） |
| **ちびキャラ** | 2〜3頭身、かわいいプロポーション | ファンアート・グッズ |
| **スケッチ風** | ラフな鉛筆タッチ、下書き的 | コンセプトアート・エモい表現 |
| **ポップアート** | ドット・原色・大胆な色面構成 | 広告・インパクト重視 |

### 4.2 ジャンル

ストーリーのジャンルを選ぶと、シーンの雰囲気に影響します。

| ジャンル | 画像への影響 |
|---------|------------|
| アクション | 動的なポーズ、インパクト表現 |
| ラブコメ | 暖かい照明、柔らかい表情 |
| ホラー | 暗い影、不穏なムード |
| 日常 | 自然なポーズ、親しみやすい雰囲気 |
| SF | 未来的テクノロジー、ネオンライト |
| ファンタジー | 魔法的要素、異世界的雰囲気 |
| ミステリー | 劇的なライティング、緊張感 |
| スポーツ | 動的なモーション、汗と努力 |
| 歴史 | 時代考証的ディテール、古典的雰囲気 |

### 4.3 カラーモード

色の使い方を選びます。

| モード | 説明 | 用途 |
|--------|------|------|
| **モノクロ** | 白黒のみ。スクリーントーン的表現 | 伝統的な漫画 |
| **フルカラー** | 全色使用 | ウェブトゥーン・SNS漫画 |
| **セピア** | セピア調の暖かいトーン | ノスタルジー・回想シーン |
| **限定色** | 指定した数色のみ使用 | デザイン性の高い作品 |
| **パステル** | 淡い色合い | 優しい・癒し系の作品 |
| **ネオン** | 蛍光色・発光感 | サイバーパンク・クラブ系 |

### 4.4 線のスタイル

輪郭線の質感を選びます。

| スタイル | 説明 |
|---------|------|
| **太線** | 力強い印象。少年漫画向き |
| **細線** | 繊細で上品。少女漫画向き |
| **ラフ** | 手描き感のある味わい |
| **クリーン** | なめらかで均一。デジタル感 |
| **ブラシ** | 筆タッチの抑揚のある線。和風・アート系 |

### 4.5 カラーパレット

「+」ボタンで色を追加し、作品全体の配色を指定できます。限定色モードと組み合わせると効果的です。

### 4.6 カスタムプロンプト

上記の選択肢では表現しきれない指示を自由に追加できます。

**入力例:**
- `Studio Ghibli inspired, soft lighting`
- `1990s retro anime aesthetic`
- `dark and moody, film noir atmosphere`
- `Tezuka Osamu style, classic manga`

### 4.7 プロンプトプレビュー

「プロンプトプレビューを表示」をクリックすると、現在の設定から生成されるプロンプト文字列を確認できます。画像生成AIにはこの文字列が渡されます。

## 5. 漫画を生成する

### 手順

1. プロジェクト詳細ページで「生成」ボタンをクリック
2. テキストエリアにストーリーを入力
3. 「漫画を生成」をクリック

### 生成の流れ

生成は4つのステップで進みます。

| ステップ | 処理内容 | 所要時間の目安 |
|---------|---------|--------------|
| 1. ストーリー解析 | Claude AIがテキストを読み取り、漫画の構成を考えます | 5〜15秒 |
| 2. パネル分割 | ストーリーを4〜8コマに分割し、各コマのシーン説明・セリフ・効果音を決定します | ステップ1に含む |
| 3. 画像生成 | 各コマの画像を並列で生成します（最も時間がかかるステップ） | 15〜60秒 |
| 4. 保存 | 生成結果をデータベースに保存します | 1〜3秒 |

生成が完了すると、自動的にコマ割りエディタに移動します。

## 6. コマ割りエディタで編集する

生成された漫画を編集できます。

### 6.1 パネルの並べ替え

各パネルの左上にあるドラッグハンドル（点のアイコン）を掴んで、ドラッグ＆ドロップで並び替えられます。

### 6.2 セリフの編集

1. パネルにマウスを乗せると「編集」ボタンが表示されます
2. クリックすると編集モーダルが開きます
3. 編集できる項目:

| 項目 | 説明 |
|------|------|
| **シーン説明** | パネルの視覚的な説明。再生成時のプロンプトになります |
| **セリフ** | キャラクター名・テキスト・スタイル（通常/心の声/ナレーション/叫び）を設定 |
| **効果音** | 「ドカーン」「シーン...」などの効果音テキスト |

4. 「保存」をクリック

### 6.3 セリフスタイルの使い分け

| スタイル | 表示 | 用途 |
|---------|------|------|
| **通常（speech）** | 吹き出し | 通常の会話 |
| **心の声（thought）** | 雲型吹き出し | 内面のモノローグ |
| **ナレーション（narration）** | 四角い枠 | 状況説明・地の文 |
| **叫び（shout）** | トゲ付き吹き出し | 驚き・怒りの大声 |

### 6.4 パネルの再生成

パネルにマウスを乗せて「再生成」ボタンをクリックすると、そのパネルの画像だけを再生成できます。シーン説明を編集してから再生成すると、異なる結果が得られます。

## 7. PNG・PDFで出力する

エディタ画面の右上にあるボタンで出力します。

| ボタン | 出力形式 | 用途 |
|--------|---------|------|

## 8. 設定画面でAPIキーを管理する

サイドバーの「設定」から、各サービスのAPIキーを登録できます。

### APIキーの取得方法

| プロバイダー | 取得先 | 備考 |
|------------|--------|------|
| OpenAI | OpenAI Platform のAPI Keys | gpt-image-1 の利用権限が必要 |
| Stability AI | Stability AI の Developer Portal | SDXL/SD3 の利用権限が必要 |
| Google Gemini | Google AI Studio | Imagen API の有効化が必要 |

### 設定項目

- **表示名**: ダッシュボードに表示される名前
- **デフォルトプロバイダー**: 新規プロジェクト作成時のデフォルト
- **APIキー**: 各プロバイダーのキーを登録

APIキーはサーバーサイドでのみ使用されます。

## 9. ストーリーの書き方のコツ

AIが漫画に変換しやすいテキストを書くためのポイントです。

### 基本ルール

1. **場面を具体的に書く** — 「学校」ではなく「朝の教室、窓から陽が差している」
2. **キャラクターの行動を明確に** — 「タロウが驚く」ではなく「タロウが目を見開いて一歩後ずさる」
3. **セリフを含める** — 会話があるとコマが生き生きします
4. **4〜8場面に収まる長さ** — 短すぎず長すぎないストーリーが最適

### 良い例

```
朝の教室。チャイムが鳴り終わった直後、タロウが息を切らして
教室のドアを開ける。「セーフ！」と叫ぶが、先生は腕を組んで
待っている。

「田中、今週3回目だぞ」と先生が呆れた顔で言う。
クラスメイトが忍び笑い。

隣の席のハナコが小声で「ノート見せてあげるよ」と言って
微笑む。タロウは感激して「ありがとう！」と小声で返す。

放課後。夕日の差す廊下で、タロウがハナコを呼び止める。
「今日は本当に助かった。お礼にアイスおごるよ」
ハナコが笑って「じゃあ抹茶味ね」と答える。
```

### 悪い例

```
タロウとハナコが仲良くなる話。学校が舞台。
```

→ 抽象的すぎてAIが場面を想像しにくい

### キャラクター名の統一

- ストーリー中のキャラクター名は、事前に登録したキャラクター名と**完全一致**させてください
- 「タロウ」で登録した場合、ストーリーでも「タロウ」を使います（「太郎」「たろう」ではマッチしません）

## 11. よくある質問（FAQ）

### Q. 生成に失敗します

**A.** 以下を確認してください:
- 設定画面でAPIキーが正しく入力されているか
- 選択したプロバイダーのAPIキーが有効か
- APIの利用制限（レートリミット・残高）に達していないか

プロジェクト詳細ページの「生成履歴」でエラーメッセージを確認できます。

### Q. キャラクターの見た目が毎回変わります

**A.** 画像生成AIの特性上、完全な一貫性は難しい部分があります。以下で改善できます:
- **画像生成用プロンプト**をより具体的・詳細にする
- 髪型、髪色、服装、特徴的なアクセサリーを明記する
- OpenAIプロバイダーは指示追従性が比較的高い

### Q. 生成されるコマ数を変えたいです

**A.** ストーリーテキストの長さや場面数で調整できます:
- 短いテキスト（1〜2場面）→ 4コマ程度
- 中程度のテキスト（3〜5場面）→ 5〜6コマ
- 長いテキスト（6場面以上）→ 7〜8コマ

### Q. セリフや効果音を後から変更できますか？

**A.** はい。コマ割りエディタで各パネルの「編集」ボタンからセリフ・効果音を自由に追加・変更・削除できます。

### Q. 1つのパネルだけ画像を変えたいです

**A.** エディタでパネルにマウスを乗せて「再生成」ボタンをクリックしてください。シーン説明を編集してから再生成すると、違うイメージの画像が得られます。

### Q. プロバイダーごとに画像の雰囲気は違いますか？

**A.** はい、プロバイダーによって得意分野が異なります:
- **OpenAI**: 指示に忠実。万能型
- **Stability AI**: アニメ・イラスト調が得意
- **Gemini**: 写実的な表現が得意

同じストーリーでもプロバイダーを変えると全く違う雰囲気の作品になります。

### Q. 生成した漫画を商用利用できますか？

**A.** 各画像生成AIサービスの利用規約に従ってください:
- OpenAI: 生成画像の商用利用可（利用規約確認推奨）
- Stability AI: ライセンスに依存
- Gemini: Google の利用規約に従う

詳細は各サービスの最新の利用規約をご確認ください。

### Q. 日本語でストーリーを入力していいですか？

**A.** はい、日本語でストーリーを入力してください。AIが内容を理解し、画像生成用のプロンプトは自動的に英語に変換されます。

## クイックスタート（5分で最初の漫画を作る）

最短手順で漫画を1つ作ってみましょう。

1. **アカウント作成** — `/signup` で登録
2. **プロジェクト作成** — 「新規プロジェクト」→ タイトルを入力 → トンマナはデフォルトのまま → 「作成」
3. **生成** — プロジェクト詳細の「生成」→ ストーリーを入力 → 「漫画を生成」
4. **確認** — エディタで生成結果を確認
5. **出力** — 「PNG出力」で画像をダウンロード

まずはデフォルト設定で試して、慣れてきたらトンマナやキャラクターをカスタマイズしていきましょう。
