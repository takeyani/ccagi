# 業務フロー定義書

## 概要

本システムは、メーカー・代理店・クリエイター・バイヤーの4つのロールが連携する成果報酬型マーケットプレイスです。
商品の登録から販売・決済・送金までの全フローを以下に定義します。

---

## ロール一覧

| ロール | 説明 | 新規登録 | ログイン | 画面 |
|--------|------|---------|---------|------|
| 管理者 | システム全体の管理 | バックエンドで設定 | メール/Google `/login` | `/admin` |
| メーカー | 商品の登録・ロット管理・承認管理 | `/signup?role=maker` | メール/Google `/login` | `/partner` |
| 代理店 | メーカー商品の販売（承認制） | `/signup?role=agent` | メール/Google `/login` | `/partner` |
| クリエイター | LP作成・アフィリエイト販売 | `/affiliate`（チェックボックス） | コード認証 `/creator` | `/creator` |
| 紹介者 | アフィリエイトリンクで紹介 | `/affiliate` | 不要（コード発行のみ） | なし |
| バイヤー | 商品の購入・AIエージェント検索 | `/signup?role=buyer` | メール/Google `/login` | `/buyer` |

### 入口の動線

```
トップページ (/)
  ├─ ヘッダー「新規登録」→ /signup（ロール選択: メーカー/代理店/バイヤー）
  ├─ ヘッダー「ログイン」→ /login
  ├─ ヘッダー「クリエイター / 紹介者」→ /affiliate
  ├─ Hero「はじめてガイド」→ /guide/start
  ├─ Hero「紹介して報酬を得る」→ /guide/referral
  └─ エコシステムセクション → 各ロール別CTA
       ├─ メーカー登録 → /signup?role=maker
       ├─ 代理店登録 → /signup?role=agent
       ├─ クリエイター登録 → /affiliate
       └─ バイヤー登録 → /signup?role=buyer

一般ユーザー向けガイド:
  /guide/start    → やりたいこと別の始め方案内（購入/紹介/クリエイター/メーカー/代理店）
  /guide/referral → 紹介の仕方・報酬体系ガイド（メーカー1%/代理店1%/クリエイター0.5%/購入者2%）
```

## フロー1: メーカー登録 → 商品販売

```
新規登録(/signup?role=maker) → メール or Google認証
  ↓
ロール選択で「メーカー」を選択
  ↓
user_profiles 作成（role: partner）
partners 作成（partner_type: メーカー, certification_status: 未認証）
  ※ ?ref= パラメータがある場合 → referred_by_affiliate_id に紹介者を記録
  ※ 紹介者には以降の売上に対して1%の継続報酬が発生
  ↓
パートナーダッシュボード(/partner)
  ↓
商品登録(/partner/products/new)
  ├─ 基本情報（名前、説明、画像、価格）
  ├─ カテゴリ選択（11種: 食品/ホテル/イベント/映像 等）
  ├─ カテゴリ固有フィールド（動的表示）
  └─ タグ・属性設定
  ↓
ロット作成(/partner/lots/new)
  ├─ 在庫数・ステータス
  ├─ 販売単位（個/箱/ケース/パレット）
  ├─ 配送方法・送料
  ├─ 卸価格（代理店向け）
  └─ 賞味期限・仕入情報
  ↓
商品ページ公開(/products/[slug]/[lotId])
  ↓
バイヤーが購入 → 決済フローへ
```

## フロー2: 代理店登録 → 承認取得 → 販売

```
新規登録(/signup?role=agent) → メール or Google認証
  ↓
ロール選択で「販売代理店」を選択
  ↓
user_profiles 作成（role: partner）
partners 作成（partner_type: 代理店, certification_status: 未認証）
  ↓
パートナーダッシュボード(/partner)
  ↓
商品承認リクエスト(/partner/authorizations)
  ├─ 販売したい商品を選択
  ├─ メッセージを添えて申請
  └─ status: 申請中
  ↓
メーカーが承認管理画面で確認
  ├─ 承認 → status: 承認済み
  └─ 却下 → status: 却下
  ↓
承認済み商品の販売が可能に
  ↓
卸価格確認(/partner/wholesale) → ロット編集(/partner/lots/[id])で価格設定
```

## フロー3: メーカーからの承認付与

```
メーカーが承認管理画面を開く(/partner/authorizations)
  ↓
「承認を付与する」フォーム
  ├─ 対象商品を選択
  ├─ 承認先（代理店 or クリエイター）を選択
  └─ 許可アクション（販売/LP作成/価格設定）
  ↓
承認レコード作成（status: 承認済み, requested_by: メーカー）
```

## フロー4: クリエイターのLP作成 → 販売

```
アフィリエイト登録(/affiliate)
  ├─ 名前・メールアドレス入力
  └─ 「クリエイターとして登録する」チェックボックスON
  ↓
アフィリエイトコード発行（例: yamada-abc1）
  ↓
クリエイターコードで認証(/creator)
  ↓
クリエイターダッシュボード
  ├─ デザイン作成(/creator/designs/new)
  │     ├─ 商品・ロット選択
  │     └─ テンプレート選択（5種: スタンダード/ミニマル/セールス特化/ストーリー型/健康食品）
  ├─ LP編集(/creator/designs/[id]/edit)
  │     ├─ ブロック追加・並べ替え・複製・削除
  │     ├─ テーマプリセット切替（7色）
  │     └─ プレビュー確認 → 保存
  ├─ コレクション作成(/creator/collections/new)
  ├─ アクセス分析(/creator/analytics)
  └─ プロフィール管理(/creator/profile)
  ↓
LP公開
  ├─ 公開URL: /c/[code]/[slug]/[lotId]
  └─ 埋め込み: /embed/lp/[code]/[slug]/[lotId]
  ↓
購入 → アフィリエイト報酬発生
```

## フロー5: 紹介者のアフィリエイト

```
アフィリエイト登録(/affiliate)
  ├─ 名前・メールアドレス入力
  └─ クリエイターチェックなし
  ↓
アフィリエイトコード発行
  ↓
紹介リンク: /?ref={code} をSNS等で共有
  ↓
紹介先が購入 → 売上の2%がアフィリエイト報酬
```

## フロー6: バイヤーの購入

```
商品ページ閲覧(/products/[slug]/[lotId])
  ├─ 商品情報・カテゴリ固有情報表示
  ├─ 販売単位（個/箱/ケース/パレット）・最小注文数確認
  ├─ 数量選択（±ボタン、最小注文数〜在庫上限）
  ├─ メーカー認証バッジ確認
  ├─ Q&A・アンケート参加
  ├─ 非財務アンケート（感謝・感動・選択理由）
  └─ 定期購入フォーム（毎週/隔週/毎月/隔月）
  ↓
「今すぐ購入する（○箱）」ボタン → 決済フロー（数量反映）
 or
「定期購入で申し込む」→ 定期購入フロー（数量反映）
```

## フロー7: AIエージェント購入（バイヤー）

```
バイヤー登録(/signup?role=buyer) → ログイン
  ↓
バイヤーダッシュボード(/buyer)
  ↓
AIエージェント作成(/buyer/agents/new)
  ├─ キーワード・タグ条件
  ├─ 価格帯・認証要件
  ├─ スペック要件（成分、原材料等）
  ├─ メーカー種別・在庫要件
  └─ 認証重み・プルーフチェーン重み
  ↓
AIが条件に合う商品を自動検索・5軸スコアリング
  ├─ 認証スコア（認証済み=100, 未認証=30）
  ├─ プルーフチェーンスコア（L1:30% + L2:40% + L3:30%）
  ├─ タグ一致スコア
  ├─ スペック一致スコア
  └─ 価格スコア
  ↓
結果確認(/buyer/agents/[id]/results)
  ├─ 注文フォーム（価格・数量・コメント）→ パートナーへ引合い
  └─ 却下ボタン → 結果から除外
  ↓
パートナーが引合い対応(/partner/inquiries/[id])
  ├─ 承諾 → 取引成立
  └─ 辞退 → 辞退理由をバイヤーに通知
```

## フロー8: 決済フロー（単品購入）

```
購入ボタンクリック（数量選択: ±ボタンで個/箱/ケース/パレット単位）
  ↓
POST /api/checkout (lot_id, quantity, ref)
  ├─ ロット在庫チェック（販売中 & 在庫 >= 数量 & 期限内）
  ├─ 最小注文数チェック（quantity >= min_order_units）
  ├─ reserve_lot_stock RPC で在庫を数量分 原子的に予約（p_quantity対応）
  ├─ アフィリエイトコード検証
  └─ Stripe Checkout Session 作成
      ├─ line_items: quantity = 購入数量（販売単位ごと）
      ├─ メタデータ: lot_id, product_id, partner_id, selling_unit, quantity, shipping情報
      └─ 成功URL / キャンセルURL
  ↓
Stripe決済画面
  ↓
決済完了 → /success
  ↓
Webhook (checkout.session.completed)
  ├─ lot_purchases レコード作成（冪等性保証）
  ├─ アフィリエイト報酬計算・記録
  ├─ LPアナリティクス コンバージョンイベント記録
  ├─ ステップメール登録
  ├─ メーカー紹介者報酬計算
  └─ Stripe Connect → メーカーへ自動送金
      └─ 売上総額 - プラットフォーム手数料(12%) - アフィリエイト報酬(2%) = メーカー受取額
```

## フロー9: 定期購入フロー

```
商品ページ(/products/[slug]/[lotId])で定期購入フォーム入力
  ├─ 頻度選択: 毎週 / 隔週 / 毎月 / 隔月
  ├─ 顧客名・メールアドレス
  └─ 数量
  ↓
POST /api/recurring
  ├─ ロット在庫予約（初回分）
  ├─ 次回配送日を自動計算
  ├─ recurring_orders レコード作成（status: 有効）
  └─ Stripe Checkout Session 作成（初回決済）
  ↓
Stripe決済 → 定期購入開始
  ↓
パートナーが管理(/partner/recurring, /partner/recurring/[id])
  ├─ 一覧確認（商品、顧客、頻度、次回配送日）
  └─ ステータス変更（有効 / 一時停止 / 解約）
```

## フロー10: オークション

```
パートナーがオークション作成(/partner/auctions/new)
  ├─ ロット選択
  ├─ 開始価格・即決価格
  └─ 終了日時
  ↓
オークションページ公開(/products/[slug]/[lotId]/auction)
  ├─ 手動入札
  ├─ 即決購入
  └─ 購買エージェントの自動入札（auto_rebid_for_auction RPC）
  ↓
落札 → POST /api/auctions/checkout → Stripe決済
  ↓
Webhook → auctions.status = '落札済み'
```

## フロー11: ASPアフィリエイト（外部サイト連携）

```
管理者がASP広告主を登録(/admin/asp/advertisers/new)
  ├─ サイト名・ドメイン・連絡先
  ├─ 報酬率・Cookie有効期間
  └─ APIキー/シークレット自動生成
  ↓
ASPプログラム作成(/admin/asp)
  ├─ プログラム名・LP URL
  ├─ 報酬タイプ（成果報酬/クリック報酬/リード報酬）
  └─ 報酬金額/率
  ↓
外部サイトに埋め込みスクリプト設置
  └─ GET /api/asp/tracking.js → Cookie管理・クリック追跡
  ↓
ユーザーがクリック → POST /api/asp/click → click_id発行
  ↓
コンバージョン発生 → POST /api/asp/conversion → 報酬計算
  ↓
アフィリエイター確認(/affiliate/asp) → 参加プログラム・報酬確認
```

## フロー12: 非財務アンケート収集

```
商品ページ閲覧(/products/[slug]/[lotId])

ページ下部「お客様の声をお聞かせください」フォーム

  ↓
RAGデータベースに蓄積 → AI分析・レポート生成（pgvector有効化後）
```

## フロー14: エージェントの自動実行

```
Cronスケジュール（vercel.json 登録済み）
  ├─ /api/cron/step-mail    … 毎日 0:00 UTC
  ├─ /api/cron/agents       … 6時間ごと（UTC 0,6,12,18時）
  └─ /api/cron/sales-agent  … 毎日 8:00 UTC
  ※ 全エンドポイント CRON_SECRET Bearer認証必須

購買エージェント自動実行（GET /api/cron/agents）
  ├─ 有効な購買エージェントを最大20件取得
  ├─ 各エージェントに対して run_buying_agent RPC を実行
  ├─ 条件に合う商品を自動検索・5軸スコアリング
  └─ 結果をagent_resultsに保存 → バイヤーが確認

販売エージェント自動モニタリング（GET /api/cron/sales-agent）
  ├─ 在庫アラート: stock <= 5 のロット → パートナーに通知
  ├─ 引合いリマインダー: 24時間以上未対応 → パートナーに通知
  └─ 賞味期限アラート: 14日以内 → パートナーに通知

パートナー販売エージェント画面（/partner/sales-agent）
  ├─ KPI: 販売中ロット/未対応引合い/過去30日販売/在庫アラート
  ├─ 在庫少ロットのアラート表示（赤）
  ├─ 未対応引合い一覧
  └─ 販売中ロット一覧テーブル
```

## 対応カテゴリ（11種）

| # | カテゴリ | 手数料 | 固有フィールド例 |
|---|---------|--------|----------------|
| 1 | 食品・飲料 | 12% | アレルゲン、成分表、栄養成分、保存方法、賞味期限 |
| 2 | 化粧品・美容 | 15% | 成分、容量、肌タイプ、製造販売業許可 |
| 3 | 家電・電子機器 | 8% | 電圧、PSEマーク、技適マーク、保証期間 |
| 4 | アパレル・ファッション | 15% | 素材構成、サイズ展開、カラー、洗濯表示 |
| 5 | サービス・デジタル | 20% | 提供エリア、利用規約、キャンセルポリシー |
| 6 | 医薬品・医療機器 | 10% | 承認番号、分類、有効成分、副作用 |
| 7 | 工業製品・部品 | 6% | 適合規格(JIS/ISO)、公差、材質グレード |
| 8 | ホテル・宿泊施設 | 10% | 部屋タイプ、チェックイン/アウト、食事、駐車場 |
| 9 | イベント・チケット | 10% | 開催日時、会場、席種、チケット種別、定員 |
| 10 | 映像・動画コンテンツ | 15% | コンテンツ種別、解像度、ライセンス種別、著作権者 |
| 11 | 一般商品 | 12% | ブランド、型番、保証期間、商品状態 |

## 認証方式

| 方式 | 対象 | 新規登録 | 実装 |
|------|------|---------|------|
| メール/パスワード | メーカー・代理店・バイヤー | `/signup` でロール選択 | Supabase Auth |
| Google OAuth | メーカー・代理店・バイヤー | `/signup` でロール選択 → OAuth | Supabase + Google Cloud |
| クリエイターコード | クリエイターのみ | `/affiliate` でコード発行 | affiliates.code で認証 |
| パスワードリセット | メール/パスワードユーザー | `/forgot-password` → メール → `/reset-password` | Supabase Auth |

## 5層プルーフチェーン

| レイヤー | 名称 | 内容 |
|---------|------|------|
| L1 | 主体証明 (entity_proofs) | パートナーの身元確認 |
| L2 | 商品証明 (product_proofs) | 成分表・検査結果 |
| L3 | 在庫証明 (inventory_proofs) | 写真・バーコードで在庫確認 |
| L4 | 所有権記録 (ownership_records) | 出品→購入→落札の履歴 |
| L5 | 配送証明 (delivery_proofs) | 追跡番号・署名確認 |
