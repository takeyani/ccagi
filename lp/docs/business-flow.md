# 業務フロー定義書

## 概要

本システムは、メーカー・代理店・クリエイター・バイヤーの4つのロールが連携する成果報酬型マーケットプレイスです。
商品の登録から販売・決済・送金までの全フローを以下に定義します。

---

## ロール一覧

| ロール | 説明 | ログイン方法 | 画面 |
|--------|------|-------------|------|
| 管理者 | システム全体の管理 | メール/Google `/login` | `/admin` |
| メーカー | 商品の登録・ロット管理・承認管理 | メール/Google `/login` | `/partner` |
| 代理店 | メーカー商品の販売（承認制） | メール/Google `/login` | `/partner` |
| クリエイター | LP作成・アフィリエイト | コード認証 `/creator` | `/creator` |
| バイヤー | 商品の購入・AIエージェント検索 | メール/Google `/login` | `/buyer` |

---

## フロー1: メーカー登録 → 商品販売

```
新規登録(/signup) → メール or Google認証
  ↓
パートナー自動作成（partner_type: メーカー）
  ↓
商品登録(/partner/products/new)
  ├─ 基本情報（名前、説明、画像、価格）
  ├─ カテゴリ選択（11種: 食品/ホテル/イベント/映像 等）
  ├─ カテゴリ固有フィールド（動的表示）
  └─ タグ・属性設定
  ↓
ロット作成(/partner/lots/new)
  ├─ 在庫数・ステータス
  ├─ 販売単位（個/箱/ケース/パレット）
  ├─ 配送方法・送料
  └─ 賞味期限・仕入情報
  ↓
商品ページ公開(/products/[slug]/[lotId])
  ↓
バイヤーが購入 → 決済フローへ
```

## フロー2: 代理店の承認取得 → 販売

```
新規登録(/signup) → パートナー自動作成
  ↓
商品承認リクエスト(/partner/authorizations)
  ├─ 販売したい商品を選択
  ├─ メッセージを添えて申請
  └─ status: 申請中
  ↓
メーカーが承認管理画面で確認
  ├─ 承認 → status: 承認済み
  └─ 却下 → status: 却下
  ↓
承認済み商品の販売が可能に
```

## フロー3: メーカーからの承認付与

```
メーカーが承認管理画面を開く
  ↓
「承認を付与する」フォーム
  ├─ 対象商品を選択
  ├─ 承認先（代理店 or クリエイター）を選択
  └─ 許可アクション（販売/LP作成/価格設定）
  ↓
承認レコード作成（status: 承認済み, requested_by: メーカー）
```

## フロー4: クリエイターのLP作成 → 販売

```
クリエイターコードで認証(/creator)
  ↓
クリエイターダッシュボード
  ├─ デザイン作成(/creator/designs/new)
  ├─ コレクション作成(/creator/collections/new)
  └─ アクセス分析(/creator/analytics)
  ↓
LP公開 → embed対応(/embed/lp/[code]/[slug]/[lotId])
  ↓
購入 → アフィリエイト報酬発生
```

## フロー5: バイヤーの購入

```
商品ページ閲覧(/products/[slug]/[lotId])
  ├─ 商品情報・カテゴリ固有情報表示
  ├─ 販売単位（箱/ケース等）・最小注文数確認
  ├─ メーカー認証バッジ確認
  └─ Q&A・アンケート参加
  ↓
「今すぐ購入する」ボタン
  ↓
決済フローへ
```

## フロー6: AIエージェント購入（バイヤー）

```
バイヤーダッシュボード(/buyer)
  ↓
AIエージェント作成
  ├─ キーワード・タグ条件
  ├─ 価格帯・認証要件
  ├─ スペック要件
  └─ メーカー種別・在庫要件
  ↓
AIが条件に合う商品を自動検索・スコアリング
  ↓
結果から購入
```

## フロー7: 決済フロー

```
購入ボタンクリック
  ↓
POST /api/checkout
  ├─ ロット在庫チェック（販売中 & 在庫 > 0 & 期限内）
  ├─ reserve_lot_stock RPC で在庫を原子的に予約
  ├─ アフィリエイトコード検証
  └─ Stripe Checkout Session 作成
      ├─ メタデータ: lot_id, product_id, selling_unit, shipping情報
      └─ 成功URL / キャンセルURL
  ↓
Stripe決済画面
  ↓
決済完了 → /success
  ↓
Webhook → lot_purchases レコード作成
  ↓
Stripe Connect → メーカーへ自動送金
  └─ 売上総額 - プラットフォーム手数料 - アフィリエイト報酬 = メーカー受取額
```

## フロー8: 管理者の運用

```
管理者ダッシュボード(/admin)
  ├─ 商品管理（全商品のCRUD）
  ├─ ロット管理（全ロットのCRUD）
  ├─ パートナー管理
  ├─ タグ管理
  ├─ オークション管理
  ├─ アフィリエイト管理
  ├─ クリエイターデザイン管理
  ├─ マーケティング分析
  └─ 定期購入管理
```

## 対応カテゴリ（11種）

| # | カテゴリ | 手数料 | 固有フィールド例 |
|---|---------|--------|----------------|
| 1 | 食品・飲料 | 12% | アレルゲン、成分表、栄養成分、保存方法、賞味期限 |
| 2 | 化粧品・美容 | 15% | 成分、容量、肌タイプ、製造販売業許可 |
| 3 | 家電・電子機器 | 8% | 電圧、PSEマーク、技適マーク、保証期間 |
| 4 | アパレル・ファッション | 15% | 素材構成、サイズ展開、カラー、洗濯表示 |
| 5 | サービス・デジタル | 20% | 提供エリア、利用規約、キャンセルポリシー |
| 6 | 医薬品・医療機器 | 10% | 承認番号、分類、有効成分、副作用 |
| 7 | 工業製品・部品 | 6% | 適合規格(JIS/ISO)、公差、材質グレード |
| 8 | ホテル・宿泊施設 | 10% | 部屋タイプ、チェックイン/アウト、食事、駐車場 |
| 9 | イベント・チケット | 10% | 開催日時、会場、席種、チケット種別、定員 |
| 10 | 映像・動画コンテンツ | 15% | コンテンツ種別、解像度、ライセンス種別、著作権者 |
| 11 | 一般商品 | 12% | ブランド、型番、保証期間、商品状態 |

## 認証方式

| 方式 | 対象 | 実装 |
|------|------|------|
| メール/パスワード | 全ユーザー | Supabase Auth |
| Google OAuth | 全ユーザー | Supabase + Google Cloud |
| クリエイターコード | クリエイターのみ | affiliates.code で認証 |

---

## 5層プルーフチェーン

| レイヤー | 名称 | 内容 |
|---------|------|------|
| L1 | 主体証明 (entity_proofs) | パートナーの身元確認 |
| L2 | 商品証明 (product_proofs) | 成分表・検査結果 |
| L3 | 在庫証明 (inventory_proofs) | 写真・バーコードで在庫確認 |
| L4 | 所有権記録 (ownership_records) | 出品→購入→落札の履歴 |
| L5 | 配送証明 (delivery_proofs) | 追跡番号・署名確認 |
