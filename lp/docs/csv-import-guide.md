# 商品CSV一括登録ガイド

## 概要

CSVファイルを使って商品を一括登録できます。最大500件/回。

## アクセス

パートナーポータル → 商品管理 → **CSV一括登録**

URL: `/partner/products/import`

## CSVフォーマット

### 必須カラム

| カラム名 | 型 | 説明 | 例 |
|---------|---|------|---|
| `name` | テキスト | 商品名 | 有機玄米 5kg |
| `slug` | テキスト | URL用スラッグ（英数字とハイフン） | organic-rice-5kg |
| `base_price` | 数値 | 税込価格（円） | 3500 |

### 任意カラム

| カラム名 | 型 | 説明 | デフォルト |
|---------|---|------|----------|
| `description` | テキスト | 商品説明文 | なし |
| `image_url` | URL | 商品画像のURL | なし |
| `category` | テキスト | カテゴリID（food, cosmetics, electronics等） | なし |
| `min_order_quantity` | 数値 | 最小注文数 | 1 |
| `min_order_amount` | 数値 | 最小注文金額 | なし |
| `order_notes` | テキスト | 注文時の注意事項 | なし |

### 注意事項（価格・販売単位）

- **価格上限:** ¥500,000（超過は登録エラー）
- **価格最低:** ¥1 以上
- **商品名:** 2文字以上

ロットを作成する際の **販売単位** は以下が利用可能です：

`個` / `箱` / `ケース` / `パレット` / `kg` / `L` / `セット` / `本` / `袋` / `缶` / `瓶` / `枚` / `台` / `式`

### カテゴリID一覧

| ID | カテゴリ名 |
|---|----------|
| food | 食品・飲料 |
| cosmetics | 化粧品・美容 |
| electronics | 家電・電子機器 |
| apparel | アパレル・ファッション |
| service | サービス・デジタル |
| medical | 医薬品・医療機器 |
| industrial | 工業製品・部品 |
| hotel | ホテル・宿泊施設 |
| event | イベント・チケット |
| video | 映像・動画コンテンツ |
| general | 一般商品 |

## テンプレート

CSVテンプレートは登録画面から直接ダウンロードできます。

```csv
name,slug,base_price,description,image_url,category,min_order_quantity
有機玄米 5kg,organic-rice-5kg,3500,国産有機栽培の玄米です,,food,1
天然はちみつ 300g,natural-honey-300g,2800,北海道産の天然はちみつ,,food,1
```

## 注意事項

- 1行目はヘッダー行（必須）
- 文字コード: UTF-8
- カンマを含む値はダブルクォートで囲む: `"東京都渋谷区,1-2-3"`
- 一度に登録できるのは500件まで
- `slug` は商品ごとにユニーク（重複不可）
- 登録後、各商品にロット（在庫）を追加する必要があります

## エラー対応

| エラー | 原因 | 対策 |
|--------|------|------|
| name, slug, base_price は必須です | 必須カラムが空 | 該当セルに値を入力 |
| base_price が不正です | 数値でない | 半角数字のみ入力 |
| duplicate key value | slug が重複 | ユニークなslugに変更 |
